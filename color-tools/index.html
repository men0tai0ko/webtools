WCAGコントラスト基準とは?

Web Content Accessibility Guidelines(WCAG)が定める、文字と背景の見やすさの基準です。「大きな文字」は18pt(約24px)以上、または太字14pt(約18.5px)以上が目安です。AA基準は一般的な達成目標、AAAはより厳しい基準です。

配色抽出の仕組み

アップロードした画像を縮小してピクセルごとの色を集計し、近い色同士をまとめたうえで出現頻度が高い色を上位6色抽出しています。外部APIやライブラリは使わず、Canvas APIだけで完結しています。
